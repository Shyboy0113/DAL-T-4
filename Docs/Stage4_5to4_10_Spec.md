## 범례

```
[S ] = Start              [G ] = FirstDestination(Map1 전용)
[G2] = SecondDestination(Map2 전용)
[. ] = None(바닥)         [H ] = Help         [★ ] = Star
[So] = StepOn             [Tg] = ToggleTargeted(초기=막힘)
[To] = ToggleTargeted(초기=열림)
[Tr] = TrapToggle(초기=OFF, 위험)   [Tr*] = TrapToggle(초기=ON, 안전)
[CoR] = ColorToggle(Red)  [TgR] = ToggleTargeted(Red, 초기=막힘)
[TrR] = TrapToggle(Red, 초기=OFF)
[E1] = EnemySpawn(Map1)   [E2] = EnemySpawn(Map2)
[Q>] = QuarterCW(시계 90° 회전)
[Ct] = ConditionalToggle
[  ] = 이동 불가(벽/공백)
```

**듀얼 맵 규칙:**

- Map1 전용: G (FirstDestination), E1 (Map1 적)
- Map2 전용: G2 (SecondDestination), E2 (Map2 적)
- 적은 **같은 맵에 플레이어가 있을 때만** 이동. 다른 맵에 있으면 제자리 정지.
- TAB(ALT+TAB): 플레이어가 서있는 좌표에 **두 맵 모두 타일이 존재**할 때만 전환 가능

**클리어 조건:** G(Map1) + G2(Map2) 둘 다 도달 시 클리어 (G2가 있는 경우)

## 적(Enemy) AI 규칙

- 플레이어가 같은 맵에 있을 때: 매 3 플레이어 행동마다 1칸 최단 경로 이동
- 플레이어가 다른 맵으로 전환 시: 적 제자리 정지 (행동 카운트 정지)

## 4-5 : EnemySpawn 시험 — 양쪽 맵에 적

**의도:** Map1과 Map2 모두에 적이 있어서 단순 TAB 전환으로 회피 불가.
양쪽 맵의 적 위치를 파악하고 충돌 없는 경로를 계획해야 함.
TAB으로 Map2 이동 시 E1은 멈추지만 E2가 추적 시작 → 둘 다 신경 써야 한다.

**타일 수:** Map1: 7 / Map2: 5 | **limitTAB:** 3, **limitALT:** 8 | **레이아웃:** 2행 병렬

=== MAP 1 ===

```
┌──────┬──────┬──────┬──────┐
│  S   │  .   │  E1  │  H   │  ← r1
├──────┼──────┼──────┼──────┤
│      │  .   │  .   │  G   │  ← r0
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

- E1(c2r1) 초기 위치. 플레이어가 Map1에 있을 때 추적.
- G(c3r0) = FirstDestination

=== MAP 2 (G2 없음) ===

```
┌──────┬──────┬──────┬──────┐
│      │  .   │  .   │      │  ← r1
├──────┼──────┼──────┼──────┤
│  E2  │  .   │  ★   │      │  ← r0
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

- E2(c0r0) 초기 위치. 플레이어가 Map2에 있을 때 추적.
- ★(c2r0)

**TAB 가능 위치:** c1r1, c2r1, c1r0, c2r0 (Map1·Map2 모두 타일 존재)

**기본 클리어 경로 (TAB 없이):**

```
S(c0r1) → c1r1 → c1r0 → c2r0 → G(c3r0)
```

E1은 r1 행에서 추적. 플레이어가 r0 행으로 내려가면 E1은 아래로 방향을 틀어야 함.
이동 3회 = 3 플레이어 행동 → E1은 아직 1번도 못 움직임(3행동 필요). G 도달 전에 위협 없음.

**★ 획득 조건:**

★(Map2 c2r0): TAB으로 Map2에 진입 후 E2를 피하며 c2r0 도달.

```
S → c1r1 → [TAB] Map2(c1r1) → c1r0 → c2r0(★)
  → [TAB] Map1(c2r0) → G(c3r0)
```

E2는 c0r0에서 시작. Map2에서 2칸 이동해야 c2r0 도달 = 6 플레이어 행동 소요.
Map2에서 플레이어가 c2r0까지 이동(2행동) 후 바로 TAB 귀환 → E2 위협 전 탈출 가능.

★ 의도: "Map2에도 적이 있다. TAB만 하면 안전하지 않다" — 리스크 판단 학습.

**사망 함정:**

- E1/E2가 있는 칸으로 이동 = 즉사
- Map2에 오래 머물면 E2가 접근 → 충돌

**H 힌트 위치:** Map1(c3r1)
**힌트 의도:** "다른 맵에도 적이 있을 수 있어요"

## 4-6 : EnemySpawn + StepOn 복합

**의도:** So를 밟아 Tg를 열어야 E1을 피한 안전 경로가 열린다.
So → Tg 순서가 강제되며, Tg가 열리면 E1이 추적 시작 → 신속히 이동.

**타일 수:** Map1: 9 / Map2: 4 | **limitTAB:** 3, **limitALT:** 6, **limitF4:** 8 | **레이아웃:** L자

=== MAP 1 ===

```
┌──────┬──────┬──────┬──────┐
│  S   │  So  │  H   │      │  ← r2
├──────┼──────┼──────┼──────┤
│      │  Tg  │  .   │  E1  │  ← r1  (Tg 초기=막힘)
├──────┼──────┼──────┼──────┤
│      │  .   │  .   │  G   │  ← r0
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

**연결 설정:**

- So(c1r2) ──► Tg(c1r1) 초기=막힘

E1(c3r1): So 발동 후 플레이어 추적 시작.

=== MAP 2 (G2 없음) ===

```
┌──────┬──────┬──────┐
│  .   │  .   │      │  ← r1
├──────┼──────┼──────┤
│  ★   │  .   │      │  ← r0
└──────┴──────┴──────┘
  c1    c2    c3
```

- ★(c1r0 in Map2)

**TAB 가능 위치:** c1r1, c2r1, c1r0, c2r0 (두 맵 공통)

**기본 클리어 경로:**

```
S(c0r2) → So(c1r2)  [Tg 열림, E1 추적 시작]
         → Tg(c1r1) 통과
         → c1r0 → c2r0 → G(c3r0)
```

E1(c3r1)은 오른쪽에서 추적. 플레이어는 왼쪽/하단 경로로 우회.
E1이 c2r0으로 내려오려면 2이동(6행동) 필요 → 플레이어는 3~4행동 이내 G 도달 가능.

**★ 획득 조건:**

★(Map2 c1r0): TAB으로 Map2 진입 후 c1r0 도달.

```
S → So(Tg 열림) → Tg(c1r1) → [TAB at c1r1] Map2(c1r1)
  → c1r0(★) → [TAB] Map1(c1r0) → c2r0 → G(c3r0)
```

Map2에 E2 없음 → 안전하게 수집 가능. TAB 2회 소비.

★ 의도: "So+Tg 통과 후 TAB으로 Map2 탐색 가능" — 듀얼 맵 활용 심화.

**사망 함정:**

- So 밟지 않고 Tg 접근 → 막힘
- Tg 열린 후 E1이 추적 → 하단 경로로 신속 이동 필요

**H 힌트 위치:** Map1(c2r2)
**힌트 의도:** "이 타일을 밟으면 막힌 길이 열려요"

## 4-7 : TAB + Enemy + TrapToggle 복합

**의도:** Map1의 CoR을 밟아야 Map2의 TrR이 안전해진다. 맵 간 ColorToggle 연동.
E1 회피 + TrR 해제 + G·G2 두 목적지 달성이 모두 필요.

**타일 수:** Map1: 7 / Map2: 6 | **limitTAB:** 3, **limitALT:** 6, **limitF4:** 8 | **레이아웃:** ㅁ자

=== MAP 1 ===

```
┌──────┬──────┬──────┬──────┐
│  S   │  CoR │  E1  │  H   │  ← r1
├──────┼──────┼──────┼──────┤
│      │  .   │  .   │  G   │  ← r0
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

**연결 설정:**

- CoR(c1r1) ──► TrR(Map2 c1r1) ON/OFF 전환

E1(c2r1): CoR 발동 여부와 무관하게 추적.

=== MAP 2 ===

```
┌──────┬──────┬──────┬──────┐
│      │  TrR │  .   │  G2  │  ← r1  (TrR 초기=OFF, 위험)
├──────┼──────┼──────┼──────┤
│      │  .   │  ★   │  H   │  ← r0
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

- TrR(c1r1) 초기=OFF (위험. 밟으면 즉사). CoR(Map1) 발동 시 ON(안전)으로 전환.
- G2(c3r1) = SecondDestination
- ★(c2r0)

**TAB 가능 위치:** c1r1, c2r1, c3r1, c1r0, c2r0, c3r0

**전체 클리어 경로 (TAB 2회):**

```
1. Map1: S(c0r1) → CoR(c1r1)  [TrR in Map2 → ON]
2. c1r0 → [TAB at c1r0] Map2(c1r0=.)
3. Map2: c1r0 → TrR(c1r1, 이제 안전) → c2r1 → G2(c3r1) ✓
4. [TAB at c3r1] Map1(c3r1=H) → c3r0(G) ✓
```

limitTAB=3 중 2회 사용. 1회 여유.

E1(c2r1 in Map1): CoR 밟은 후 추적 시작. TAB으로 Map2 이동 시 E1 정지.
Map1 귀환 시(c3r1) E1이 근처에 있을 수 있음 → c3r0(G)까지 신속 이동.

**★ 획득 조건:**

★(Map2 c2r0): G2 달성 후 또는 전 Map2 탐색 중 수집.

```
3번 단계에서: Map2 c1r0 → c2r0(★) → c1r0 → TrR(c1r1) → c2r1 → G2(c3r1)
```

TAB 추가 소비 없이 Map2 내부 경로만으로 ★ 수집 가능.

★ 의도: "TrR이 켜진 Map2에서 이동하며 ★ 수집" — 안전해진 후 탐색 심화.

**사망 함정:**

- CoR 밟기 전 Map2 TrR에 진입 → 즉사 (TrR이 OFF 상태)
- CoR 재밟기 → TrR 다시 OFF → Map2에서 TrR 위에 있으면 폭발
- E1이 c3r1 방향으로 내려올 수 있음 → Map1 귀환 후 빠른 G 도달

**H 힌트 위치:** Map1(c3r1), Map2(c3r0)
**힌트 의도:** "빨간 타일을 먼저 밟아야 저쪽 맵의 위험이 사라져요"

## 4-8 : Enemy + 회전 타일 — 회전으로 E1 위치 변동

**의도:** Q>(시계 90° 회전 타일)를 밟으면 맵 전체가 회전 → E1의 상대적 위치가 바뀐다.
회전 전후 E1 위치를 예측하고 안전한 경로를 찾아야 함.

**타일 수:** Map1: 8 / Map2: 5 | **limitTAB:** 3, **limitALT:** 6, **limitF4:** 7 | **레이아웃:** L자

=== MAP 1 ===

```
┌──────┬──────┬──────┬──────┐
│  S   │  Q>  │  E1  │  H   │  ← r1
├──────┼──────┼──────┼──────┤
│      │  .   │  .   │  G   │  ← r0
├──────┼──────┼──────┼──────┤
│      │  ★   │      │      │  ← r-1
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

- Q>(c1r1): 밟으면 맵 90° 시계방향 회전. E1 포함 모든 타일 좌표 변환됨.
- E1(c2r1) 초기 위치.
- ★(c1r-1)

**회전 후 좌표 변환 (Q> 중심 기준 CW 90°):**

Q>(c1r1)을 중심으로 회전 시 (Δc, Δr) → (Δr, -Δc):

- E1(c2r1): Δ(+1, 0) → (0, -1) → E1은 Q> 아래(c1r0)로 이동
- ★(c1r-1): Δ(0, -2) → (-2, 0) → ★은 Q> 왼쪽 2칸(c-1r1)으로 이동 (맵 밖일 수 있음)
- G(c3r0): Δ(+2, -1) → (-1, -2) → G는 Q> 아래-왼쪽(c0r-1)으로 이동

> **구현 참고:** 실제 회전 결과는 엔진 구현에 따라 다를 수 있음. 설계 의도는 "Q>를 밟으면 E1이 G로 가는 직선 경로에서 벗어난다"는 것. 구현 후 실측 검증 필요.

=== MAP 2 (G2 없음, 안전 공간) ===

```
┌──────┬──────┬──────┐
│  .   │  .   │  H   │  ← r1
├──────┼──────┼──────┤
│  .   │  .   │      │  ← r0
└──────┴──────┴──────┘
  c1    c2    c3
```

Map2는 E2 없는 안전 공간. 회전 전 E1 위협 회피용 임시 대피 가능.

**TAB 가능 위치:** c1r1, c2r1, c1r0, c2r0

**기본 클리어 경로 (회전 활용):**

```
S(c0r1) → Q>(c1r1)  [맵 90° CW 회전 → E1 위치 변동]
         → (회전 후 새 좌표로) G 접근
```

회전 전 E1이 경로를 막고 있음. Q> 밟은 후 E1이 안전한 위치(G 방향이 아닌 곳)로 이동했으면 직진 가능.

**TAB 활용 경로 (회전 대신):**

```
S(c0r1) → c1r1(Q> 밟지 않고 우회) → [TAB] Map2(c1r1)
         → Map2 안전 이동 → [TAB] Map1(E1 위치 확인) → G
```

Q> 없이 TAB으로 E1을 일시 정지시키고 G 방향 접근 가능.

**★ 획득 조건:**

★(Map1 c1r-1): 기본 클리어 후 아래 경로로 접근.
Q> 밟기 전 또는 E1이 원거리에 있을 때 c1r-1 방문.

★ 의도: "회전 전/후 ★ 위치가 달라진다 — 언제 수집해야 할지 판단" — 회전 영향 범위 이해.

**사망 함정:**

- Q> 밟은 후 E1 새 위치 미확인 → 예상치 못한 충돌
- 회전 후 G 위치 변경 → 이전 경로가 막힐 수 있음

**H 힌트 위치:** Map1(c3r1), Map2(c3r1)
**힌트 의도:** "저 타일을 밟으면 전체 맵이 회전해요"

## 4-9 : 브릿지 — TAB + Enemy 정리 스테이지

**의도:** 4-8과 4-10 사이 복잡도 완충. 이전 패턴(TAB, 적 회피) 정리 + 여유 있는 클리어.
Map1 단독 경로와 Map2(G2) 경로 모두 유효 → 플레이어 선택.

**타일 수:** Map1: 8 / Map2: 6 | **limitTAB:** 4, **limitALT:** 7, **limitF4:** 8 | **레이아웃:** T자

=== MAP 1 ===

```
┌──────┬──────┬──────┬──────┐
│      │  .   │  .   │  H   │  ← r1
├──────┼──────┼──────┼──────┤
│  S   │  .   │  E1  │  G   │  ← r0
├──────┼──────┼──────┼──────┤
│      │  ★   │      │      │  ← r-1
└──────┴──────┴──────┴──────┘
  c0    c1    c2    c3
```

- E1(c2r0): 플레이어와 G 사이에 위치.
- ★(c1r-1): E1이 근처에 있어 위험한 위치.

**경로 A (상단 우회, TAB 없음):**

```
S(c0r0) → c1r1 → c2r1 → c3r1(H) → G(c3r0)
```

E1은 r0에서 추적하지만 플레이어가 r1 행을 사용하므로 직접 충돌 없음.

=== MAP 2 ===

```
┌──────┬──────┬──────┐
│  .   │  .   │  H   │  ← r1
├──────┼──────┼──────┤
│  .   │  G2  │      │  ← r0
├──────┼──────┼──────┤
│  ★   │      │      │  ← r-1
└──────┴──────┴──────┘
  c1    c2    c3
```

- G2(c2r0) = SecondDestination
- ★(c1r-1 in Map2) — Map1의 ★와 같은 좌표(c1r-1)

**TAB 가능 위치:** c1r0, c2r0, c1r1, c2r1 (두 맵 공통)

**경로 B (Map2 G2 포함, TAB 2회):**

```
S(c0r0) → c1r1 → [TAB at c1r1] Map2(c1r1)
         → c2r1 → G2(c2r0) ✓
         → [TAB at c2r0] Map1(c2r0=E1?) → 위험!
```

TAB 귀환 위치(c2r0)가 Map1에서 E1 위치. 귀환 직후 이동 필요.

안전한 귀환:

```
Map2 G2(c2r0) → c1r0 → [TAB] Map1(c1r0) → c2r1 → c3r1 → G(c3r0) ✓
```

**★ 획득 조건:**

★ 의도: "같은 위치(c1r-1)라도 Map1은 위험, Map2는 안전 — TAB 활용의 가치 재확인."

- E1과 같은 칸 이동 = 즉사
- Map1 c2r0는 E1 위치 → 귀환 시 주의

**H 힌트 위치:** Map1(c3r1), Map2(c3r1)
**힌트 의도:** "여러 방법으로 목적지에 도달할 수 있어요"

## 4-10 : ConditionalToggle 첫 소개

**의도:** "G에 도달하면 Ct가 발동 → Map2의 막힌 길(Tg2)이 열린다"는 ConditionalToggle 핵심 인지.
ch3 리마인더(So+Tg) + 신규 메커닉(Ct) 연속 학습.

**타일 수:** Map1: 6 / Map2: 4 | **limitTAB:** 3, **limitALT:** 6, **limitF4:** 7 | **레이아웃:** 직선

=== MAP 1 ===

```
┌──────┬──────┬──────┬──────┬──────┐
│  S   │  So  │  Tg  │  Ct  │  G   │  ← r0
├──────┼──────┼──────┼──────┼──────┤
│      │  H   │      │      │      │  ← r-1
└──────┴──────┴──────┴──────┴──────┘
  c0    c1    c2    c3    c4
```

**연결 설정:**

- So(c1r0) ──► Tg(c2r0) 초기=막힘 ← ch3 So+Tg 리마인더
- Ct(c3r0) ──► Tg2(Map2 c2r0) 초기=막힘 ← 신규 ConditionalToggle

So 밟으면 Tg 열림 → Ct 밟으면 Map2 Tg2 열림 → G 도달.
G와 Map2 G2의 좌표 동일(c4r0) → G에서 TAB 가능.

=== MAP 2 ===

```
┌──────┬──────┬──────┐
│  .   │  Tg2 │  G2  │  ← r0   (Tg2 초기=막힘)
├──────┼──────┼──────┤
│  ★   │      │      │  ← r-1
└──────┴──────┴──────┘
  c2    c3    c4
```

- Tg2(c3r0) 초기=막힘. Ct(Map1 c3r0) 발동 후 열림.
- G2(c4r0) = SecondDestination
- ★(c2r-1)
- G(Map1 c4r0)와 G2(Map2 c4r0)는 **같은 좌표** → G 도달 후 TAB으로 G2 직행 가능

**TAB 가능 위치:** c2r0, c3r0, c4r0 (두 맵 공통)

**기본 클리어 경로 (TAB 1회):**

```
S(c0r0) → So(c1r0)  [Tg 열림]
         → Tg(c2r0) 통과
         → Ct(c3r0)  [Map2 Tg2 열림]
         → G(c4r0)   [Map1 클리어]
         → [TAB at c4r0] → G2(c4r0 in Map2) ✓  [전체 클리어]
```

limitTAB=3 중 1회만 사용. 여유 2회.

**★ 획득 조건 (TAB 3회):**

★(Map2 c2r-1): Ct 발동 전 Map2에 TAB 진입 후 수집. Tg2가 아직 닫혀 있어 G2는 접근 불가.

```
S → So(Tg 열림) → Tg(c2r0) → [TAB at c2r0] Map2(c2r0=.)
  → c2r-1(★) → c2r0 → [TAB] Map1(c2r0=Tg, 이미 열림)
  → Ct(c3r0)  [Tg2 열림]
  → G(c4r0) → [TAB] G2(c4r0 in Map2) ✓
```

TAB 3회 사용 (limitTAB=3 정확히 소진).

★ 의도: "Ct 발동 전 Map2에 가봤자 Tg2가 닫혀 G2에 못 간다. 먼저 Ct를 눌러야 한다" — ConditionalToggle 인과 학습.

**사망 함정:**

- Ct 발동 전 Map2에서 G2 방향 시도 → Tg2 막힘 (게임오버 아님, 학습 유도)
- So 없이 Tg 접근 → 막힘 (ch3 리마인더 재확인)

**H 힌트 위치:** Map1(c1r-1)
**힌트 의도:** "저 타일을 밟으면 다음 칸이 열려요 (So 힌트)"
