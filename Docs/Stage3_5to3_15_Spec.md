## 적(Enemy) AI 규칙 — 설계 기준

- 플레이어를 향해 매 턴 최단 경로로 1칸 이동
- **경로가 막힌 경우(Tg 닫힘 등):** 이동 불가 방향은 무시, 도달 불가 시 제자리 정지
- **TrapToggle(OFF):** 위험 타일로 인식하지 않음 → 해당 칸 위를 이동하면 즉시 폭발 사망
- **TrapToggle(ON):** 안전한 바닥으로 인식, 정상 이동
- **플레이어가 텔레포트 등으로 접근 불가 위치에 있는 경우:** 적 제자리 정지

## 3-5 : ColorToggle 첫 소개 — Red 단색

**의도:** "CoR을 밟으면 같은 색 TgR이 반응한다"는 1:1 대응 체험
**타일 수:** 7 | **limit:** 없음 | **레이아웃:** L자

```
┌──────┬──────┬──────┐
│  S   │  CoR │  H   │  ← row 0
├──────┼──────┼──────┤
│      │  TgR │  ★   │  ← row 1
├──────┼──────┼──────┤
│      │  .   │  G   │  ← row 2
└──────┴──────┴──────┘
```

**연결 설정:**

- CoR ──► TgR (Red ColorToggle → Red ToggleTargeted)
- TgR 초기 = 막힘

**기본 클리어 경로:**

```
S → CoR (Red 이벤트 발생 → TgR 열림)
  → 아래 이동: TgR 통과
  → 오른쪽: G
```

**★ 획득 조건:**
TgR 통과 후 G로 가기 전 오른쪽(★)을 먼저 수집.
기본 경로와 거의 동일하지만 G 이전에 ★ 칸을 한 번 더 방문해야 함.
★ 의도: "TgR이 열린 상태에서 한 칸 더 이동해야 한다" — ColorToggle 상태 유지 확인 심화.

**사망 함정:**

- CoR 밟지 않고 TgR 접근 → 막힘 → "색 타일을 먼저" 자연 인지
- CoR 재밟으면 TgR 다시 닫힘 → 통과 불가 (재시도 교육)

**H 힌트 위치:** CoR 옆 (r0,c2)
**힌트 의도:** "같은 색 타일을 찾아보세요"

## 3-7 : So + ColorToggle 복합 — 두 종류 트리거가 공존

**의도:** StepOn(So)과 ColorToggle(CoR) 두 종류가 각각 독립된 Tg를 제어
플레이어가 둘의 역할을 구분하며 순서를 판단해야 함
**타일 수:** 9 | **limit:** 없음 | **레이아웃:** T자

```
┌──────┬──────┬──────┬──────┐
│  S   │  So  │  H   │  CoR │  ← row 0
├──────┼──────┼──────┼──────┤
│      │  Tg  │      │  TgR │  ← row 1   (둘 다 초기=막힘)
├──────┼──────┼──────┼──────┤
│      │  .   │  .   │  G   │  ← row 2
├──────┼──────┼──────┼──────┤
│      │  ★   │      │      │  ← row 3
└──────┴──────┴──────┴──────┘
```

**연결 설정:**

- So(r0,c1) ──► Tg(r1,c1)
- CoR(r0,c3) ──► TgR(r1,c3)
- Tg 초기 = 막힘
- TgR 초기 = 막힘

**기본 클리어 경로:**

```
S(r0,c0) → So(r0,c1)   [Tg 열림]
           → Tg(r1,c1) 통과
           → .(r2,c1) → .(r2,c2) → G(r2,c3)
           (CoR/TgR은 무시 가능)
```

**★ 획득 조건:**
★(r3,c1)에 도달하려면 Tg 통과 후 .(r2,c1) → ★(r3,c1) 수집 → 복귀 → G.
추가로, CoR → TgR 열기를 선택하면 G로 가는 오른쪽 경로도 열림 (어느 방향으로도 G 접근 가능).
★ 의도: "So로 Tg를 열었을 때 그 아래로 내려갈 수 있다" — So 발동 후 탐색 심화.

**사망 함정:**

- So 재밟으면 Tg 다시 닫힘 → .(r2,c1)에서 위로 올라오다가 막힘 (역방향 봉쇄)

**H 힌트 위치:** r0,c2
**힌트 의도:** "서로 다른 모양의 타일이 각각 다른 곳을 열어줍니다"

## 3-8 : So + CoR + CoB 3종 트리거 — 경로 선택 심화

**의도:** 3종류 트리거가 각각 독립된 Tg를 제어. 클리어 경로는 1개지만 ★ 수집엔 2개 이상 활성화 필요
**타일 수:** 11 | **limit:** 없음 | **레이아웃:** 복합 분기

```
┌──────┬──────┬──────┬──────┐
│  CoR │  H   │  CoB │      │  ← row 0
├──────┼──────┼──────┼──────┤
│  TgR │      │  TgB │      │  ← row 1   (초기=막힘)
├──────┼──────┼──────┼──────┤
│  .   │  So  │  .   │      │  ← row 2
├──────┼──────┼──────┼──────┤
│  .   │  Tg  │  .   │  G   │  ← row 3   Tg 초기=막힘
├──────┼──────┼──────┼──────┤
│  ★   │      │      │      │  ← row 4
└──────┴──────┴──────┴──────┘
```

**연결 설정:**

- CoR(r0,c0) ──► TgR(r1,c0)
- CoB(r0,c2) ──► TgB(r1,c2)
- So(r2,c1) ──► Tg(r3,c1)
- 모든 Tg 초기 = 막힘

**기본 클리어 경로:**

```
S 위치: r2,c1 (So와 겹침) 또는 인접 칸에서 시작

So(r2,c1) → Tg(r3,c1) 열림 → .(r3,c0) 또는 .(r3,c2) → G(r3,c3)
(CoR, CoB 없이도 클리어 가능)
```

> **S 배치 추천:** r2,c0 (So 왼쪽)

**★ 획득 조건:**
★(r4,c0)는 TgR이 열려야 접근 가능한 경로 위에 배치.
CoR → TgR(r1,c0) 열림 → .(r2,c0)? → 아래 → ★ 경로가 뚫림.
★ 의도: "So만으로는 ★에 못 간다. CoR도 써야 한다" — 2종 트리거 동시 활용 학습.

**사망 함정:**

- So 두 번 밟으면 Tg 다시 닫힘 → 이미 Tg 너머에 있으면 복귀 경로 봉쇄

**H 힌트 위치:** r0,c1
**힌트 의도:** "모양마다, 색깔마다 반응하는 타일이 따로 있어요"

## 3-9 : EnemySpawn 첫 등장 — StepOn으로 적 동선 차단

**의도:** "StepOn으로 ToggleTargeted(열림→닫힘)를 발동시키면 적의 경로가 막힌다"
플레이어가 능동적으로 적을 차단해야 안전해지는 첫 스테이지

**타일 수:** 10 | **limit:** 없음 | **레이아웃:** L자

```
┌──────┬──────┬──────┬──────┐
│  E1  │  To  │      │  H   │  ← row 0   To = ToggleTargeted(초기=열림)
├──────┼──────┼──────┼──────┤
│      │      │      │      │  ← row 1
├──────┼──────┼──────┼──────┤
│  S   │  So  │  .   │  G   │  ← row 2
├──────┼──────┼──────┼──────┤
│      │  .   │  ★   │      │  ← row 3
└──────┴──────┴──────┴──────┘
```

**연결 설정:**

- So(r2,c1) ──► To(r0,c1)
- **To 초기 = 열림** (E1이 처음부터 아래로 이동 가능)
- So를 밟으면 To가 닫힘(막힘) → E1 이동 차단

**적 이동 패턴:**
E1(r0,c0)은 플레이어를 향해 이동. 초기에는 To(r0,c1)이 열려 있어 아래 방향으로 진행 가능.
플레이어가 So를 밟아 To를 닫으면 E1은 r0,c0에서 더이상 이동 불가 → 제자리 정지.

**기본 클리어 경로:**

```
S(r2,c0) → So(r2,c1)   [To 닫힘 → E1 차단]
           → .(r2,c2) → G(r2,c3)
```

타이밍: So를 밟기 전에 E1이 너무 내려오면 위험. 첫 이동으로 So를 밟는 것이 최선.

**★ 획득 조건:**
★(r3,c2)는 기본 경로에서 한 칸 아래.
클리어 경로: S → So → .(r2,c2) → ★(r3,c2) → 복귀 → G.
E1이 차단된 이후에는 안전하게 수집 가능.
★ 의도: "적을 차단하고 나서 여유 있게 탐색할 수 있다" — So 차단 기법 숙달 확인.

**사망 함정:**

- So를 밟지 않고 G로 이동 시도 → E1이 하단으로 내려와 충돌
- So를 두 번 밟으면 To 다시 열림 → E1 재이동

**H 힌트 위치:** r0,c3
**힌트 의도:** "적이 오는 길을 막아보세요"

## 3-10 : TrapToggle 첫 등장 — 적이 TrapToggle로 자멸

**의도:** TrapToggle(OFF) = 플레이어/적 모두 위험. 적은 위험 인식 불가 → 스스로 걸어들어가 사망.
플레이어는 Tr을 우회, 적은 직선 경로상 Tr을 밟아 자멸.

**타일 수:** 10 | **limitALT:** 8 | **레이아웃:** ㄷ자

```
┌──────┬──────┬──────┬──────┐
│  E1  │  Tr  │      │  H   │  ← row 0   Tr 초기=OFF(위험)
├──────┼──────┼──────┼──────┤
│      │      │  .   │      │  ← row 1
├──────┼──────┼──────┼──────┤
│  S   │  .   │  .   │  G   │  ← row 2
├──────┼──────┼──────┼──────┤
│      │  ★   │      │      │  ← row 3
└──────┴──────┴──────┴──────┘
```

**설정:**

- Tr(r0,c1) 초기 = OFF (위험. 플레이어가 밟으면 폭발)
- E1(r0,c0): 플레이어 추적. 최단 경로가 Tr(r0,c1)을 통과하므로 자멸

**적 이동 경로 (자멸 패턴):**

```
E1(r0,c0) → Tr(r0,c1) [OFF 상태] → 폭발 사망
```

E1 입장에서 플레이어(r2,c0~c3)로 가는 최단 경로가 r0,c1(Tr)을 통과함.
Tr이 위험 타일임을 인식하지 못해 직진 → 자멸.

**플레이어 클리어 경로:**

```
S(r2,c0) → .(r2,c1) → .(r2,c2) → G(r2,c3)
(Tr을 밟지 않고 하단 우회, E1은 Tr에서 자멸)
```

**★ 획득 조건:**
★(r3,c1). E1이 Tr에서 자멸한 후 안전해진 시점에 하단 탐색.
경로: S → .(r2,c1) → ★(r3,c1) [E1 자멸 확인 후] → 복귀 → G.
★ 의도: "적이 TrapToggle에서 죽었다. 그럼 나도 밟으면 죽겠구나" — Tr의 위험성 체험.

**사망 함정:**

- 플레이어가 Tr(r0,c1)을 호기심에 밟으면 폭발 → TrapToggle의 위험성 직접 체험 (교육 목적)
- Tr 위로 이동하는 경로 시도 = 폭발

**H 힌트 위치:** r0,c3
**힌트 의도:** "주황색 타일은 켜져 있을 때만 안전해요" (OFF 상태 경고)

**설계 포인트:**

- TrapToggle 첫 등장 → 플레이어가 ON/OFF 개념 인지 전에 "적의 자멸"로 시각적 체험 먼저
- 플레이어가 Tr을 키는 트리거(So, CoR 등)가 이 스테이지에는 없음 → "켤 수 없는 함정"으로 각인
- 다음 스테이지부터 "그럼 킬 수 있는 방법이 있겠구나"로 이어짐

## 3-11 : So + ColorToggle + 적 동선 통제

**의도:** CoR이 적의 경로를 바꾸는 변수. CoR 사용 여부를 전략적으로 판단해야 함
**타일 수:** 11 | **limitALT:** 6 | **레이아웃:** 2열

```
┌──────┬──────┬──────┬──────┐
```
