# DAL-T 개발 노트

---

## v1.0.8

### 버그 수정

- 인트로 신 옵션 패널에서 클릭/선택 효과음이 조절되지 않는 문제를 수정하였습니다.
- 적 사망 효과음이 조절되지 않는 문제를 수정하였습니다.
- 해상도 조절 시 미션 패널의 배치가 깨지는 문제를 수정하였습니다.
- 스테이지 선택 화면에서 Q/E 버튼 연타 시 다음 챕터로 넘어가지 않는 문제를 수정하였습니다.
- Yellow ColorToggle을 밟았을 때 하위 색상(Red, Green)의 ToggleTargeted 타일까지 함께 토글되는 버그를 수정하였습니다.
  - 기존 합집합 방식 `(CurrentTileColor & color) != 0` → 교집합 방식 `(CurrentTileColor & color) == CurrentTileColor` 으로 변경합니다.
- LeftShift를 눌러 Mission을 확인할 수 있는 UI 패널의 위치가 해상도에 따라 깨지는 버그를 수정하였습니다.
- 타일맵에서 적 로직을 관리하는 매니저가 할당돼있지 않은 문제를 수정하였습니다.
- Stage 4-4에서 ALT + TAB 로직을 사용한 뒤 Undo 시 카메라가 플레이어를 따라가지 못하는 버그를 수정하였습니다.
  - `CameraController.RestoreCameraPosition()` API를 추가하여 Undo 직후 카메라 기준 좌표를 복원합니다.

### 편의성 개선

- 스테이지 클리어 시 R키를 눌러 즉시 재시작할 수 있습니다.
- 스테이지 사이의 동선(연결선)이 해금 및 클리어 상태에 따라 시각적으로 표시됩니다.

  | 상태 | 동선 |
  |------|------|
  | 인접 스테이지가 아직 잠김 | 동선 비활성 |
  | 양쪽 모두 해금됐으나 하나 이상 미클리어 | 회색 동선 |
  | 양쪽 모두 클리어 | 노란색 동선 |

- Game Scene의 카메라를 12.5% 확대하여 타일의 가시성을 높였습니다.

### 개발자 모드 기능 구현 (DevelopmentPanel)

1. 게임 속도 조절 (0.25x / 0.5x / 1x / 2x / 4x)
2. TAB 키 횟수 제한 무시 토글
3. 미션 클리어 상태 강제 토글 (1번 / 2번 / 3번)
4. 현재 스테이지 모든 Star 즉시 수집
5. 지정 스테이지로 즉시 이동
6. 현재 스테이지 강제 클리어 / 다음 스테이지로 이동
7. 스테이지 범위 지정 해금 / 잠금
8. 전체 스테이지 해금 / 세이브 데이터 초기화
9. 지정 범위 스테이지 클리어 처리 (미션 선택 포함)
10. 실시간 게임 상태 표시 (키 카운트, 플레이어 위치, FPS 등)

### 내부 리팩토링

- 스테이지 클리어 연출 시스템을 `IStageClearEffect` 인터페이스 기반으로 재설계하였습니다.
  - `StageClearManager`가 `StageCleared` 이벤트를 수신하여 사운드 → 미션 결과 UI → 파티클 효과를 순차 실행합니다.
- 스크립트 파일을 기능별 폴더로 재정리하였습니다.
  - `Enemy/`, `Game(UI)/`, `GamePlay/`, `NonBehaviour/`, `TileMap/`
- `SO_StageData` 필드를 정리하였습니다. (`missionActionCount` 추가, `speedRunTime` 제거)
