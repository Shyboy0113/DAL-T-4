```
[h1]DAL-T-4[/h1]

[b]이동하고, 회전하고, 살아남아라.[/b]

DAL-T-4는 단 세 개의 키만으로 조작하는 타일 기반 퍼즐 게임입니다.
F4(이동) · Left ALT(회전) · TAB(맵 전환).

당신이 해야 할 일은 출발 타일에서 목적지 타일까지 도달하는 것.
하지만 그 길이 생각만큼 단순하지 않습니다.

[h2]핵심 규칙[/h2]

[b]3번의 입력이 하나의 택틱을 이룹니다.[/b]

[list]
[*] [b]F4 → ALT → ALT[/b] : 1칸 이동 후 180° 방향 전환
[*] [b]F4 → F4 → ALT[/b] : 2칸 이동 후 시계방향 90° 회전
[*] [b]ALT → ALT → ALT[/b] : 제자리에서 반시계방향 90° 회전
[*] [b]F4 → ALT → F4[/b] : 즉시 게임오버 ☠
[/list]

단순해 보이는 규칙이 레벨을 거칠수록 복잡하게 얽힙니다.

[h2]4개의 챕터, 60개 이상의 스테이지[/h2]

[b]챕터 1 — 기초[/b]
이동과 회전의 기본기를 익힙니다.
첫 번째 사망부터 규칙을 배웁니다. 설명 없이.

[b]챕터 2 — 확장[/b]
슬라이딩(Ice), 순간이동(Teleport), 부서지는 타일(Breakable).
새로운 타일이 새로운 퍼즐 문법을 만들어냅니다.

[b]챕터 3 — 복합[/b]
두 가지 이상의 메커닉이 동시에 작동합니다.
색상 기반 Toggle이 판을 통째로 바꿉니다.

[b]챕터 4 — 듀얼맵[/b]
ALT+TAB으로 두 개의 맵 사이를 전환합니다.
Map1의 적은 Map1에만 있습니다. Map2로 피하세요.
두 맵을 동시에 계산해야 클리어할 수 있습니다.

[h2]Toggle 시스템[/h2]

타일 위에 표시된 숫자가 보이나요?
그게 카운트입니다. 0이 되는 순간, 무언가 바뀝니다.

[list]
[*] [b]MoveToggle[/b] — 이동할수록 카운트 감소
[*] [b]RotateToggle[/b] — 회전할수록 카운트 감소
[*] [b]ActionToggle[/b] — 이동과 회전 합산 카운트
[/list]

Toggle 위에서 실수하면 즉시 게임오버.
우회할지, 통과할 타이밍을 잡을지 — 선택은 당신에게.

[h2]Star를 노려라[/h2]

각 스테이지에는 숨겨진 Star가 있습니다.
기본 클리어보다 더 어려운 경로에 있습니다.
Star를 얻으려다 메커닉의 새로운 면을 발견하게 될 것입니다.

[h2]특징 요약[/h2]

[list]
[*] 3개의 키로 구성된 독특한 조작 체계
[*] 25종의 타일 타입과 무한한 조합
[*] 설명 없이 레벨로 가르치는 디자인 철학
[*] 챕터 4의 듀얼맵 ALT+TAB 전환 메커닉
[*] 각 스테이지의 Star 수집 도전 요소
[*] PC 최적화 (Very Low ~ Ultra 6단계 그래픽 설정)
[/list]
```
