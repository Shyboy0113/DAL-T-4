## 굿즈 컨셉

**"타일 위의 언어"**

DAL-T-4의 핵심 시각 언어는 타일과 방향입니다.
F4 / ALT / TAB 세 개의 키, 25종의 타일, 회전하는 맵.

굿즈는 이 시각적 요소를 일상 소품에 자연스럽게 녹여내는 방향으로 기획합니다.
"게임을 모르는 사람도 디자인으로 흥미를 느낄 수 있는" 것을 목표로 합니다.

## 제품 아이디어

### 🔷 스티커팩 (추천 — 제작 진입장벽 낮음)

| 스티커 | 설명 |
|---|---|
| 타일 세트 | None / Toggle / Ice / Star / Destination 타일 미니 스티커 |
| 키 입력 | F4 · ALT · TAB 키보드 스티커 |
| 사망 패턴 | ☠ F4→ALT→F4 경고 스티커 ("이건 죽습니다") |
| 택틱 도식 | 택틱 1~4 화살표 시퀀스 도식 스티커 |

> 마플샵 기준 스티커팩 최소 5종 구성 권장

### 📮 엽서 / 아트카드

| 아이템 | 설명 |
|---|---|
| 챕터별 스테이지 일러스트 | 챕터 1~4를 대표하는 맵 장면을 미니멀 스타일로 |
| "죽어서 배운다" 문구 카드 | 게임 철학을 담은 인용구 카드 |
| Toggle 카운트 카드 | "카운트가 0이 되면 변합니다" 미니멀 디자인 |

### ☕ 머그컵

| 아이템 | 설명 |
|---|---|
| 타일맵 머그 | DAL-T-4 실제 스테이지 레이아웃을 패턴으로 인쇄 |
| 택틱 표 머그 | 4가지 택틱 시퀀스 도식이 프린트된 머그 ("내가 기억하려고 산 머그") |

### 👕 티셔츠

| 아이템 | 설명 |
|---|---|
| F4 ALT TAB 티셔츠 | 세 키를 크게 타이포로 배치 |
| 사망 패턴 후드티 | 등에 "F4 → ALT → F4 ☠" 패턴 |

### 🔑 아크릴 키링

| 아이템 | 설명 |
|---|---|
| 타일 키링 | Star 타일, Destination 타일 아크릴 키링 |
| 플레이어 캐릭터 키링 | [ 캐릭터 디자인이 확정된 경우 추가 ] |
